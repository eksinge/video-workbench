# 滚动字幕

把真实音频转成词级时间轴，再生成逐词追加、双行上滚字幕。与歌词传送带、整句预先显示、黄色卡拉 OK 高亮是不同的呈现方式。

## 默认效果

- Times New Roman Regular（比例衬线字），白色，透明底，无描边、无阴影。
- 按每个词的实际起点追加文字，不提前展示整句；停顿时保留已显示文字。
- 左对齐，按实际字体宽度折行，保留两行。新行到来时用 0.30 秒平滑上滚，窗口外文字硬裁切。
- 默认显示偏移 0；以原始词级时间为依据，按下一显示帧出现，避免提早。调整偏移时只应用一次，不改写原始对齐证据。
- 1920×1080 参考参数：字号 62、x=360、上边 y=852、行距 66、最大行宽 1160。脚本按实际画布缩放；先查看画面，按主体和参考视频调整位置、字号与宽度。

用户的新要求覆盖这些默认值。只有用户要求时才添加背景、高亮或其他动画。

## 执行流程

1. 用 ffprobe 检查输入。视频可直接提供画面和音频；单独音频需要已有底层视频或生成纯色底。独立音轨配视频时验证两者时间对应，不只比较文件名或长度。
2. **先发现已有环境与模型**：查看用户给出的路径、Subtitle Edit 的 Whisper 模型目录、已有音频工具的 Python 环境和模型缓存。使用已有兼容模型；不要重复下载 V3，不自动升级或改动别的工具环境。缺少组件时只补缺项，下载仍遵循当前用户授权。
3. `transcribe`：本地 faster-whisper Large V3 生成识别初稿。CUDA 可用时优先 `int8_float16`，CPU 使用 `int8`。不静默退化到其他模型。
4. `align`：WhisperX 使用语言相符的音素模型细化词级时间。把连续短句合成不超过约 20 秒的上下文窗口，避免逐句裁切造成边界词错位。英文默认复用本地 `WAV2VEC2_ASR_BASE_960H` 权重。数字、缩写等需要发音形式时，记录显式替换表；不要为通过对齐而悄悄改写文字。
5. 检查零时长、逆序、重叠、低分、窗口首尾及重复词。发现问题先重做相应上下文或复听；不能平均分配一段音频给单词来冒充强制对齐。脚本会拒绝无时间或不合法的词，保留草稿供修正。
6. `compile` 生成 ASS、逐词 SRT、CSV、JSON。已有可靠词级时间时直接复用，从这一步修改样式；不必重新识别和下载。
7. `render` 把字幕烧录在原底层画面上，保留选定音轨。默认 libx264，避免因新 FFmpeg 的 NVENC 驱动要求阻断导出。
8. `verify` 完整解码成片，检查时长、画布、音轨及词级边界。再查看实际解码帧与一次滚动过渡，确认字体、透明底和裁切。自动检查不等于全文听审；明确交付是初稿还是已经听审。

命令与输入格式见 [references/commands.md](references/commands.md)。辅助脚本为 [scripts/rolling_captions.py](scripts/rolling_captions.py)。

## 交付

交付可播放 MP4、可编辑 ASS 和词级 JSON/CSV；SRT 仅用于文字与时间交换，不承载上滚样式。保留原始素材、ASR、对齐证据与编译参数。只改字幕样式时复用原画面、音轨和时间轴。

处理默认在本机完成。Skill、代码与用户媒体分开存放；发布 skill 时不把原始音视频、转写全文、模型、环境目录、字体文件或个人绝对路径提交到仓库。Times New Roman 使用系统已有字体，不随包分发。不要自动清理其他项目或套用歌词 MV 的三版本保留规则。
