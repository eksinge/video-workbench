# 可选暗色剪纸视觉模板

六组可编辑HTML/SVG构图：虫翼/眼睛/人像/碎片/环形虫群/片尾。GSAP在运行`npm run setup`后从固定Node依赖复制到vendor。字体和颗粒为本地资源，不含歌曲录音、歌词或原成片。

这里的130秒和各子场景时长是模板示例，不是新歌曲的节奏分析。使用官方music-to-video流程分析用户音轨，重新布置时间线、替换YOUR SONG / YOUR ARTIST和构图。需要歌词时，先输出不含字幕的底层画面，再用统一Skill合成当前字幕效果。

参考画面可用于理解风格，但字幕规范不依赖这六组图案。民谣、电子、流行等歌曲可以采用完全不同的画面，保留相同的字幕编译器、字形填色和传送带逻辑。
